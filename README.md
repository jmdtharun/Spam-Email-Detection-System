# 📧 Spam Email Detection System

A Machine Learning based web application that detects whether an email is Spam or Legitimate using Python, Flask, MySQL, and Machine Learning.

## 🚀 Features

* 🔐 User Registration & Login
* 📧 Spam Email Detection
* 📊 Analytics Dashboard
* 📜 Prediction History
* 💾 MySQL Database Integration
* 📄 PDF Report Generation
* 🎨 Responsive UI using Bootstrap
* 🤖 Machine Learning (Naive Bayes)

## 🛠️ Technologies Used

### Frontend

* HTML5
* CSS3
* Bootstrap 5

### Backend

* Python
* Flask

### Database

* MySQL

### Machine Learning

* Scikit-Learn
* Naive Bayes
* Count Vectorizer

## ⚙️ Installation

### Clone Repository

git clone https://github.com/jmdtharun/Spam-Email-Detection-System.git

### Move to Project Folder

cd Spam-Email-Detection-System

### Install Dependencies

pip install -r requirements.txt

### Run Application

python app.py


## 📊 System Workflow

1. User Login/Register
2. Enter Email Content
3. Machine Learning Model Analysis
4. Spam/Ham Prediction
5. Store Result in MySQL
6. Generate PDF Report
7. View Prediction History
